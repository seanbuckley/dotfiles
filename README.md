# dotfiles

Sean's dotfiles for Windows, WSL and Linux, managed with [chezmoi](https://www.chezmoi.io/).

> **Status: migration in progress.** This repo is replacing two older ones. Nothing here is
> applied to a machine yet. Progress: [docs/status.md](docs/status.md).

## Supported platforms (v1)

| Platform | Profile |
|---|---|
| Windows 10 / 11 | workstation |
| WSL (Ubuntu) | workstation |
| Arch Linux (Omarchy) | workstation |
| Ubuntu Server | minimal |

Fedora and Alpine are checked in CI only; macOS comes later. Details: [docs/platforms.md](docs/platforms.md).
